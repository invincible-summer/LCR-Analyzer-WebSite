# 总览与快速上手

本站是一台**网页版 LCR 阻抗分析仪**：ESP32 采集原始 V/I 波形上传（或直接导入测量文件），网站完成阻抗求解与**等效电路辨识**。本文档覆盖拟合部分的三个引擎（Try1 / Try2 / Try3）；时域分析与扫频部分见页面内说明。

## 三种拟合引擎

| 栏目 | 已知先验 | 引擎做什么 | 输出 |
|---|---|---|---|
| **Try 1 · 未知辨识** | 无（可选器件总数） | 枚举串并联规范树库 + 参数拟合 | Top-K 候选电路 |
| **Try 2 · 已知元件** | 元件类型/数值/数量 | 穷举所有接线（含桥式） | Top-K 接线方案 |
| **Try 3 · 已知拓扑** | 拓扑 + 每边元件类型 | 多起点连续参数反演 | 唯一拟合 + 诊断 |

三者共享同一份测量数据（见《数据格式》），随先验增加，搜索空间从"全部电路"逐级收窄，速度与可信度同步上升。

## 快速上手（30 秒）

1. 打开 **电路辨识拟合** 页面；
2. 点「生成示例」或上传一份 CSV（`f, Re(Z), Im(Z)` 每行三点）；
3. Try 1 栏目直接点「运行 Try 1」——无需任何先验，几秒后得到按 AICc 排序的候选电路与电路图；
4. 若你怀疑电路含某几个已知元件，切到 Try 2 填元件表；若你已经知道接线方式，用 Try 3 画拓扑图。

## 计算发生在哪里

三个引擎是 **C++17 实现，经 WebAssembly 在你的浏览器里本地运行**——测量数据不会上传到任何服务器，断网（加载页面后）也能用。算法源码位于仓库 `AlgorithmLcr/` 目录，网页通过 `frontend/wasm/` 的桥接层（`lcr_wasm`）调用。

## 术语速查

- **器件（device）**：一个物理元件。R、C 各算 1 个；**电感是 L 与其串联直流电阻 DCR 绑定的 1 个器件**（实验室电感的绕线电阻不可忽略）。
- **wRMSE**：加权相对均方根误差（对 |Z| 归一），无量纲；`< 1e-3` 视为优。
- **AICc**：赤池信息量（小样本修正），跨候选可比，越小越好；ΔAICc < 2 视为并列。
- **等价类**：电气上不可区分（Z(f) 在频带内一致）的多个候选拍成一组合并展示。
- **端口**：单端口网络的两个端点，固定为节点 0 和节点 1。
