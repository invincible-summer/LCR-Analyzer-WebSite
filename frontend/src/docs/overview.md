# v4 开发状态

**v4 网页拟合已启用，在浏览器本地运行共享 C++ 核心（schema rev 2）。**
测量数据上传、时域分析、扫频、实时监测和实验历史继续可用。

拟合页提供 CSV（3 列或整文件统一的 6 列协方差）/示例/历史扫描导入、元件输入、
图编辑器与高级搜索设置（候选预算、starts/iterations/seed/等价容差）。
新算法既可通过 `AlgorithmLcr/` 的 C++ 命令行运行，也可在网页三个 Try 栏目中运行。
旧网页计算包已删除，不会悄悄调用旧算法。

| 模式 | 已知信息 | 输出 |
|---|---|---|
| Try1 | 可选规范等效器件数（maxN/maxDepth 独立） | 有界串并联假设内的候选类 + 选择分层 |
| Try2 Exact | 类型、数量、精确参数 | 候选接线（共同精确目标） |
| Try2 Tolerance | 类型、数量、标称参数、显式容差 | 接线及容差内参数 |
| Try3 | 图与边类型 | 可辨识聚合群的参数（多起点局部优化） |

L 与串联 DCR 算一个器件。单端口行为一般不能唯一确定内部物理接线。
`exactN` 指归约后的等效模型数量，不代表真实物理封装数量。
候选分 primary / diagnostic-only 两层：只有满足正则条件的候选参与校准
ΔAICc 排名，其余明确标记为诊断候选。
