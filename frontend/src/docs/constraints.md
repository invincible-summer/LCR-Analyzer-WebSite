# 输入约束与规模

网页拟合要求至少 4 个频点；原生标准测量文件允许至少 1 点，
但少量频点通常不足以辨识复杂模型，必须检查诊断。

| 原生默认参数范围 | 下界 | 上界 |
|---|---|---|
| R [Ω] | 1e-3 | 1e7 |
| L [H] | 1e-10 | 10 |
| C [F] | 1e-13 | 1e-3 |
| DCR [Ω] | 0 | 1e7 |

原生 CLI 可显式覆盖范围；所有普通元件值正且有限，DCR 非负且有限。
Try1 默认 maxN=4、maxDepth=4（两者相互独立，网页可分别输入）；
Try2 行数与总数硬上限 8（单行个数 1..8），E≥7 结构数以百万计，建议
Fast 或候选预算。严格枚举随规模增长迅速，不沿用旧版浏览器耗时宣传。
Fast 默认至多评价 1000 个候选，可另设时间/候选预算。
预算耗尽输出未完成状态，不能宣称枚举完整。

噪声模型三态：缺省相对加权回退；整文件统一的 6 列 CSV（f,re,im,cov_rr,
cov_ri,cov_ii，逐行正定）或仪器协方差走逐点 GLS；历史扫描可在页面上
显式 opt-in 把极坐标不确定度近似传播为协方差（近似来源，非完整波形
最小二乘协方差；任一点不满足条件整组回退）。

原生输入、网页当前表单和WASM ABI 限制分开维护，具体契约见根 DESIGN.md。
