# 约束与数量级总表

三个引擎因搜索方式不同，支持的数量级与规模不同。汇总如下，供实验设计参考。

## 输入数据

| 项 | 约束 | 建议 |
|---|---|---|
| 频率 $f$ | > 0 Hz，有限 | 10 Hz – 10 MHz，对数分布 |
| 点数 | ≥ 4 | ≥ 20（Try3：≥ max(4×储能数, 2×参数数)） |
| $\|Z\|$ 范围 | 有限 | 覆盖感性/容性渐近区与谐振 |
| 相对噪声 σ | — | ≤ 2%（参数误差中位数 < 0.5% 的验证条件） |

## 元件参数箱（拟合侧）

| 元件 | 下限 | 上限 | 单位 |
|---|---|---|---|
| R | 1e-3 | 1e7 | Ω |
| C | 1e-13 | 1e-3 | F |
| L | 1e-10 | 10 (Try1) / 1e1 (Try3) | H |
| DCR（L 串联电阻） | 1e-6 | 1e7 | Ω |

Try 2 的元件数值**不受此箱限制**（引擎不做参数搜索），但落在箱内才能与其他引擎交叉验证。

## 各引擎规模与耗时（浏览器 WASM，单线程）

| | Try 1 | Try 2 | Try 3 |
|---|---|---|---|
| 先验 | 无 / 器件数 | 元件多重集 | 拓扑 + 边类型 |
| 搜索方式 | 树枚举 + NLS | 多重图穷举 | 连续 NLS（无离散搜索） |
| 规模上限 | 器件 ≤ 6（默认 4；树库 162 @6） | 元件 E ≤ 8（推荐 ≤ 6） | 节点 ≤ 8、边 ≤ 12 |
| 典型耗时 | 0.1 – 1 s | E≤6: 0.1 – 1 s | 中位 0.1 s，p99 2 s |
| 大案例 | exact-N=6 ≈ 1 s | E=7 ≈ 37 s（故硬限 8） | 桥式秩亏仍秒级 |
| 输出 | Top-K 等价类 | Top-K 等价类 + SP 标注 | 单结果 + 诊断 |

## 器件计数规则（三引擎统一）

- R、C：各 1 个器件、1 个参数；
- **电感：L + 串联 DCR 绑定 = 1 个器件、2 个参数**（Try 1 的 R4 规则会把与 L 串联的独立 R 折入 DCR）；
- Try 3 的"群"：减支后不可再分的参数组（并联同型、串联同型、R+L 吸收）。

## 错误码

| code | 含义 | 常见原因 |
|---|---|---|
| `bad_input` | 输入不合法 | 频率 ≤ 0、点数不足、元件数值 ≤ 0、纯电阻 Try2、规模超限 |
| `port_open` | 端口开路 | Try3 拓扑在节点 0–1 间不连通 |
| `internal` | 引擎内部错误 | 请附数据反馈 |

计算在 Web Worker 中进行，任何时刻可点「取消」终止。
