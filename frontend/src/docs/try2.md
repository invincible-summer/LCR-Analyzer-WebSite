# Try 2 · 已知元件多重集的接线穷举

**适用**：你手里就是几个已知元件（从 BOM / 元件库来），不知道它们被接成了什么——引擎穷举**所有**可能接线并对测量数据打分。

## 输入

元件表（页面上的行编辑器）：每行 = 类型 + 数值 + 个数，电感额外带 DCR：

| 字段 | 含义 | 写法 |
|---|---|---|
| 类型 | R / L / C | 下拉选择 |
| 数值 | R[Ω] · L[H] · C[F] | `50`、`1e-3`、`1m`、`100n`、`4.7k` |
| DCR | 仅 L：串联直流电阻 [Ω] | 缺省 0 |
| 个数 | 该规格元件的数量 | 1–64 |

重复行 = 多个可互换元件。汇总行显示 `R×a · L×b · C×c · 共 N 个`。

## 引擎做什么

（`ng` 命名空间）两阶段枚举 + 漏斗筛选：

1. **结构层**：多重图上枚举边的槽位分布（连通、R0 死区定理、重标签群规范形去重）；
2. **指派层**：把具体元件分配到边实例（E! 排列，自同构轨道去重）；
3. **漏斗**：3 个探针频点粗筛（RSS ≤ 最优 × 1e6，至少保留 200）→ 全频点精评 → 等价类聚类。

关键特点：**元件参数已知 ⟹ 无需非线性拟合**，每个接线的 Z(f) 可精确求值，因此桥式（非串并联）拓扑也在搜索范围内。E = 6 时候选数从朴素的 9.8×10⁷ 压到 2.75×10⁴（约 3560 倍压缩）。

## 输出

Top-K 等价类：wRMSE / maxRel / RSS（AICc 退化为 RSS——参数数恒定）+ **SP 标注**（串并联 or 桥式）+ 结构键。AICc 排序原则与 Try 1 一致。

电路图：串并联接线以标准原理图呈现；**桥式接线自动切换图论视图**（节点-边布局，端口 0/1 高亮）。

## 数量级约束

| 项 | 范围 |
|---|---|
| 元件总数 E | 推荐 ≤ 6（秒级）；页面硬上限 8 |
| 元件数值 | > 0 即可（数值精确已知，引擎不做参数搜索） |
| 必备条件 | 至少 1 个 L 或 C（纯电阻网络拓扑不可辨识） |
| 频点 | 建议 ≥ 20；漏斗用 3 个探针点 |
| 耗时 | E ≤ 6 约 0.1 – 1 s；E = 7 约 37 s 量级（故限 8） |

## 解读建议

- 第 1 名 wRMSE 接近噪声底且明显低于第 2 名 ⟹ 接线唯一确定；
- 多个候选都在噪声底 ⟹ 它们电气等价（如桥式与某些梯形的对称变换），看等价类大小列；
- 元件数值标称误差（如 ±5%）会整体抬高 wRMSE 底线——只要排序稳定，第 1 名仍可信。
