# Try2 · 已知元件

网页已接入 v4 C++ / WASM，也可使用原生 CLI。
输入元件类型、参数与数量；重复元件是可互换实例，L 可给 DCR=0。
网页与原生均支持 1..8 个器件（网页行数与单行个数均为 1..8），包括纯电阻；
E≥7 时结构数以百万计，建议 Fast 模式或候选预算。

默认 **Exact** 固定所有参数，只搜索活动二端图接线，包括桥式和并联重边，
按共同精确目标排序。robust 仅用于容差模式（Exact 时网页直接禁用该选项）。
Strict 完整评价后输出 Top-K 行为类，不使用单最佳阈值提前截断 Top-K。
只有枚举完成且无数值失败时才能支持声明有限空间内最优值。

网页设置「元件容差 ±%」可启用参数拟合；默认 0 为 Exact。
原生 `--tolerance` 显式启用参数容差拟合；`--dcr-tolerance` 给额外绝对 DCR 范围。
标称零 DCR 无绝对容差时保持**固定零**（独立参数状态，不触边界、不计自由参数），
连续精调保持每元件物理身份。此时参数优化是局部方法，不具有连续全局最优证明；
若不可分别辨识，参数诊断会明确显示秩亏。
存在隐藏死枝的物理器件配置不属于活动网络搜索空间。

## 原生命令示例

```sh
lcr try2 --measurements measurements.txt --components components.txt --json
lcr try2 --measurements measurements.txt --components components.txt --tolerance .1
```

器件文件一行一个元件，不带节点号；类型 R/C 各两字段，L 可有第三字段 DCR。
输入重复行表示多个器件，并非重复测量。文件格式保持与旧版本兼容。
