# 算法背景

本文给出演算法的数学骨架；完整推导在仓库 `AlgorithmLcr/` 各课题的 `DESIGN.md`（中文，与 C++ 实现逐项同步）。网页端跑的就是这些 C++ 实现的 WebAssembly 版本。

## 统一模型

单端口 RLC 网络，驱动点阻抗 $Z(s)$，$s = j\omega$。电感为**实际电感**：

$$Z_L(s) = R_{dc} + sL$$

测量数据：$\{(f_k, Z_k)\}_{k=1}^{M}$，权重 $w_k = 1/|Z_k|$（相对误差准则）。拟合目标为加权残差

$$r_k = w_k\,\big(Z_{model}(s_k) - Z_k\big)$$

的评价，指标 $wRMSE = \sqrt{\tfrac{1}{M}\sum |r_k|^2}$，模型选择用小样本修正赤池信息量

$$AICc = 2M\ln\hat\sigma + \tfrac{2M}{M - p - 1}\,(p+1),\qquad \hat\sigma^2 = RSS / (2M)$$

其中 $p$ 为自由参数数（电感贡献 2）。

## Try 1 · 规范树枚举（rlc）

搜索空间 = 深度 ≤ 2 的串并联规范树（SER/PAR 交替）。规范化规则：R1 同层合并、R2' 同槽同型去重（并联 L 除外——两个 (L+DCR) 并联是二阶系统）、R3 子女规范序、R4 SER 节点不混 R 叶与 L 叶（串联 R 折入 DCR）。器件数 $n$ 的树库：3/6/22/45/87/162（n = 1…6）。

参数估计：log₁₀ 参数化 + **前向自动微分**的精确 Jacobian + 箱约束 Levenberg–Marquardt，多起点漏斗（粗筛 3 起点 → 精修 10 起点）。引擎 B 用 Sanathanu–Koerner 迭代有理拟合 + Foster 综合（RL/RC 单向树）回传起点。

## Try 2 · 免拟合穷举（ng）

元件参数已知 ⟹ 每个接线的 $Z(f)$ **精确可求**（节点导纳矩阵 + 单位电流注入）：

$$Y Y_{red}^{-1}[0,0] \;\Rightarrow\; Z(f)$$

结构层枚举多重图槽位分布（$E=6$ 时 31 个结构），指派层枚举元件排列（自同构轨道去重）。漏斗：3 探针点 RSS 粗筛 → 全频段精评 → 频带外扩 10×、200 点网格上的等价类聚类（$Z$ 最大相对差 < max(1e-3, 3σ̂)）。

## Try 3 · 减支 + 多起点 NLS（tf）

先做与数值无关的精确减支 F1–F4（悬空删除、同型并/串联合并、R 吸收入 DCR），把拟合参数压到可辨识群上；再在双重归一化坐标（$s/w_0$、$z/z_0$）下做多起点箱约束 LM，Jacobian 用**伴随法**解析求出。可辨识性诊断：参数弹性（弱参数）、边界触及、Jacobi 奇异值谱（秩/条件数）。

## 统一输出：上三角邻接矩阵

三个引擎的结果都化为同一格式：严格上三角 `rows[i][j]` = 节点对 (i, j) 间所有直接边的列表，每条边

$$\text{Edge} = (\text{type} \in \{R, L, C\},\; \text{parameter},\; \text{dcr})$$

节点 0/1 为端口。网站把该矩阵规约为串并联树渲染精美原理图；规约失败（桥式）则用图论视图。规约算法：度-2 内节点串联合并 → 连通分量并联合并 → 割点串联分解，三步仍剩结构即非串并联。
