# v4 算法概要

网页和原生 CLI 共享以下 v4 算法实现。

三个引擎共用 C++17 / Eigen 数学核心：完整割点死区归约、节点导纳求值、
解析 Jacobian、有界 SVD-LM、多初值、可选鲁棒拟合和统一指标。

给定节点导纳矩阵 Y 和单位端口电流 b，求解 Yv=b，端口阻抗为 Z=bᵀv。
参数导数使用 −vᵀ(∂Y/∂q)v；采用转置，不是共轭转置。
求解器显式报告开路、奇异和病态，不用巨大有限数伪装失败。

Try2 Exact 严格枚举活动二端小图，包括桥式和重边；完整可靠评价后才支持声明空间内
最优值。Tolerance 显式开启局部参数优化，不把标称值偷偷当作可调值。
Try3 先归约，再拟合群参数。Try1 枚举有界规范 SP 模型，并由可物理综合的有理拟合
提供辅助候选；不声称能恢复任意内部图。

AICc 在小样本无效域不可用。秩、条件数和标准误差仅支持局部数值判断。
噪声、系统误差和稀疏频栅可能使复杂模型排前；低误差不证明唯一物理结构。
完整数学规范与实际验收结果见仓库 `AlgorithmLcr/LCRTheory_rendered.md`、`VALIDATION.md`。
