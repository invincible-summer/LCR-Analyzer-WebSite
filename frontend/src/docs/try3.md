# Try3 · 已知拓扑

在图编辑器中输入拓扑，点击运行即可用 v4 核心拟合。
端口固定为 0/1，每条边类型为 R/L/C，允许同节点对多条边。

原生算法先删除端口不可见死区，包括只通过一个割点挂载的三角形，再做严格
串并联归约。一般并联 L+DCR 不合并；串联 R 可折入 L 的 DCR。
每个聚合群的等效参数允许域按归约表达式单调传播（串联相加、并联调和），
因此两个 rMax 串联的等效值不会被单器件全局箱排除。
拟合在聚合群上进行（多起点局部优化，无离散枚举语义），输出原边到群的映射、
聚合表达式与有效域、merged/dropped 和原节点标签。
聚合群成员的单独参数通常不可唯一辨识，输出不伪造成员单独恢复值。

诊断包含局部 Jacobian 秩、奇异值、条件数、弱参数和边界、多初值一致性，
在适用条件下给线性化标准误差。固定参数（区间收缩为一点）是独立状态，
不标记触边界；参数按显式 id/edge/quantity 描述符对齐。
单点秩亏不能直接证明全局参数族；满秩也不代表拟合收敛至全局最优。
零 DCR 是允许的真实边界。

## 原生命令示例

```sh
lcr try3 --measurements measurements.txt --topology topology.txt --json
```

拓扑文件先给节点数和上三角边数矩阵，再按槽位顺序给每条边的类型。
结果中的 members 是原输入边从零开始的序号，便于把归约群对应回实际接线。
