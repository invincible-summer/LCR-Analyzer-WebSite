# Try 3 · 已知拓扑的参数反演

**适用**：你已经知道电路怎么接、每条支路是什么类型的元件（从原理图 / 拆板目检来），只缺数值——引擎做连续参数拟合。

## 拓扑输入（图编辑器）

页面内嵌一个 **csacademy graph editor 风格**的交互编辑器：

- **绘制模式**：点画布空白处添加节点；依次点两个节点连一条边（边类型取工具条当前选中的 R/L/C；点边上的字母徽标可循环切换类型）；
- **拖动模式**：拖节点调整布局；
- **编辑模式**：点边选中，在浮出的小面板改类型或删除；
- **删除模式**：点节点（端口除外）或边删除；
- **边表**：左侧文本面板每行 `u v R|L|C`，与画布双向同步，可直接键入。

**节点 0 与 1 是单端口的两个端点**（高亮显示、不可删除），二者都必须出现在边集中，否则引擎报"端口开路"。重边（同一对节点多条边）合法——就是并联。

## 引擎做什么

（`tf` 命名空间）拟合前先做**与数值无关的精确减支**，把不可辨识的结构压掉：

- F1 自环 / 端口外连通块 / 悬空支路 → 删除；
- F2 同型并联合并（R、C）；
- F3 度-2 内节点的同型串联合并；
- F4 串联 R 吸收进相邻 L 的 DCR（$R_d \leftarrow R_d + R$）。

然后在双重归一化（频率 + 阻抗）坐标下做多起点漏斗：全箱拉丁超立方 → 中心聚焦 → 谐振配对种子 → 阻尼同伦 → 最后手段混合轮，全部使用伴随法解析 Jacobian 的**箱约束 Levenberg-Marquardt**（log₁₀ 参数）。

## 输出（单确定性结果）

- 误差：wRMSE / maxRel / AICc；
- **群参数表**：减支后每个可辨识"群"的类型、节点对、聚合模式（single/par/ser）、拟合数值（L 群两列：L 与 DCR）、成员边；
- **诊断三件套**：
  - `弱参数`：弹性 < 0.1 的群（数据对其不敏感，值仅供参考）；
  - `触边界`：拟合值贴到物理箱边界（检查电路或频段是否合理）；
  - `Jacobi 秩 / 条件数`：秩 < 参数数 ⟹ 结构性秩亏（典型如电桥），引擎只给族代表元；
- **逐边状态**：fitted / merged（并入某群）/ dropped（减支删除），附原因。

电路图：能规约为串并联的以标准原理图呈现，否则图论视图；merged/dropped 以注释列出。

## 数量级约束

| 项 | 范围 |
|---|---|
| 节点数 V | 建议 ≤ 8（页面软限 16） |
| 边数 E | 建议 ≤ 12（页面软限 16） |
| 频点数 | ≥ max(4 × 储能元件数, 2 × 参数数) |
| 参数箱 | R 1e-3–1e7 Ω · C 1e-13–1e-3 F · L 1e-10–10 H · DCR 1e-6–1e7 Ω |
| 耗时 | 中位 ≈ 0.1 s，p99 ≈ 2 s |

## 何时相信结果

2000 组战役中 **99.95% 的案例 wRMSE 收敛到噪声底**，参数中位误差 0.11%。遇到以下情况请谨慎：

1. 弱参数/触边界标记亮起——换频段重测或接受数值仅供参考；
2. 秩亏（如惠斯通电桥）——参数不唯一，只有群的组合值可辨识；
3. wRMse 明显高于噪声水平——检查拓扑是否画对、元件类型是否标错。
