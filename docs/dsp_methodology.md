# 数据处理方法（DSP Methodology）

本文档详细说明后端 `app/dsp/` 如何把 ESP32 上传的原始 V/I 波形一步步变成阻抗与等效电路参数。对应的实现文件在每节标注。

## 0. 处理流水线总览

```
原始 v[k], i[k]  (ESP32 上传, 已知 f, dt, n)
   │
   1. 去直流 + 三参数正弦拟合 (sine_fit.py)        → a, b, c
   2. 幅值 / 相位                                  → V_amp, φv,  I_amp, φi
   3. 阻抗  Z = (V_amp/I_amp)·e^{j(φv−φi)}        → |Z|, ∠Z, R, X
   4. 派生量                                       → D, Q, ESR, C/L
   5. 频谱诊断 (FFT, 加窗, spectrum.py)            → 谐波 / 噪声底
   │
   (跨频率点)
   6. 等效电路拟合 (circuit_fit.py, log 空间)      → R, L, C + 理论曲线
   7. OSL 校准 (calibration.py, 可选)              → 扣除系统误差
```

核心原则：**算阻抗值用正弦拟合，FFT 只做诊断**（理由见 §6）。

---

## 1. 采集与时间约定

ESP32 对每个激励频率 `f` 上传一条记录：采样间隔 `dt`、末索引 `n`、电压数组 `voltage[]`、电流数组 `current[]`。

```
样本数      N = n + 1
时间轴      t[k] = k · dt,        k = 0..n
采样率      f_s = 1 / dt
角频率      ω = 2π·f
```

建议每个频率采集 **≥10 个完整周期、每周期 ≥32 点**（例如 16 周期 × 64 点 = 1024 点），保证正弦拟合的统计稳定性。

---

## 2. 去直流（自动）

模型自带常数项 `c`，拟合时直接得到直流偏置，**不需要单独做 `x − mean(x)`**。这比先减均值再拟合更鲁棒——后者在非整周期采样时会引入偏差，而 `c` 项的最小二乘解不受周期数是否整数影响。

---

## 3. 三参数正弦拟合（IEEE 1057）

`app/dsp/sine_fit.py`

### 3.1 模型

激励频率 `ω` 由 ESP32 给定、已知，因此对每条序列拟合一个**已知频率**的正弦加直流：

```
x(t) ≈ a·sin(ωt) + b·cos(ωt) + c
```

三个未知参数 `θ = (a, b, c)`。这是 IEEE Std 1057 的**三参数拟合**（频率已知）。若频率也要估计，则是四参数拟合——这里不需要，因为 ESP32 自己生成的激励频率是精确已知的。

### 3.2 最小二乘求解

把模型写成矩阵形式 `M θ ≈ x`，其中设计矩阵

```
M = [ sin(ω·t_0)  cos(ω·t_0)  1 ]
    [ sin(ω·t_1)  cos(ω·t_1)  1 ]
    [   ...         ...       ...]
    [ sin(ω·t_n)  cos(ω·t_n)  1 ]
```

求解最小二乘问题 `min_θ || Mθ − x ||²`。理论闭式解为 `θ = (MᵀM)⁻¹ Mᵀx`，但代码里用 `numpy.linalg.lstsq`（基于 SVD，数值稳定，不显式求逆，对病态也能处理）：

```python
design = np.column_stack([np.sin(ω*t), np.cos(ω*t), np.ones_like(t)])
(a, b, c), *_ = np.linalg.lstsq(design, x, rcond=None)
```

对 `v` 和 `i` **各做一次**拟合，得到 `a_v,b_v,c_v` 与 `a_i,b_i,c_i`。

---

## 4. 幅值与相位

`app/dsp/sine_fit.py`

把拟合结果改写成幅值-相位形式 `A·sin(ωt + φ)`，用三角恒等式展开：

```
A·sin(ωt + φ) = (A·cos φ)·sin(ωt) + (A·sin φ)·cos(ωt)
```

对照模型系数得到 `a = A·cos φ`、`b = A·sin φ`，因此

```
A = √(a² + b²)            （幅值）
φ = atan2(b, a)           （相位，弧度）
```

**相位约定全局统一**：`v` 通道和 `i` 通道都用 `φ = atan2(b, a)`。这样求阻抗相位时做差 `∠Z = φv − φi`，约定中的任何常数都会在相减时消掉——所以阻抗相位与具体相位约定无关，只要求 V/I 一致。代码里这一不变性靠 `sine_fit` 单一实现保证。

---

## 5. 阻抗推导与派生量

`app/dsp/impedance.py`

由 V/I 的幅值比与相位差得到复阻抗：

```
|Z| = V_amp / I_amp
θ   = φv − φi
Z   = |Z| · e^{jθ} = |Z|·cos θ  +  j·|Z|·sin θ  =  R + jX
```

实部虚部及常用 LCR 参数：

```
R   = Re(Z) = |Z|·cos θ          （等效串联电阻 ESR）
X   = Im(Z) = |Z|·sin θ          （电抗）
D   = |R / X|                    （损耗因数，电容）
Q   = 1 / D                      （品质因数）
```

容性 / 感性判别与等效元件值（ω = 2πf）：

```
X < 0  →  容性,   C = −1 / (ω·X)
X > 0  →  感性,   L =  X / ω
```

---

## 6. 为什么算阻抗不用 FFT

这是本平台与"FFT 后取 V(f)/I(f)"做法的关键差异。理由：

1. **无频谱泄漏 / 栅栏效应**。FFT 在非整周期采样时主瓣能量泄漏到相邻 bin、且激励频率不一定落在某个 bin 上；要缓解就得加窗（Hann / Blackman），而加窗会改变幅值、相位也随之漂移——这对依赖虚部/相位的阻抗测量是致命的。正弦拟合在已知频率下没有这些问题。
2. **统计最优**。在加性高斯白噪声（AWGN）下，三参数正弦拟合是幅值/相位的**最大似然估计**，单频率的 SNR 优于 FFT 单 bin。
3. **样本更少也能用**。FFT 的频率分辨率 ∝ 1/T（要长采集）；正弦拟合只要几个周期就能给出可信的幅值相位。
4. **自带去直流**。模型 `c` 项直接吸收偏置，无需预处理。

**FFT 不是被丢弃，而是降级为诊断工具**——用来检查谐波失真（非线性 DUT 会在 2f₀、3f₀ 出现峰）和噪声底（见 §7）。阻抗数值从不依赖 FFT。

---

## 7. FFT 频谱（仅诊断）

`app/dsp/spectrum.py`

```
1. 去均值            x' = x − mean(x)
2. 加窗              w = Hann(N)          （抑制远端泄漏）
3. 变换              X[k] = Σ_n x'[n]·w[n]·e^{−j2πkn/N}     （numpy.fft.rfft）
4. 单边幅值谱        |X[k]| · 2/N，再乘窗的相干增益补偿 (N / Σw)
```

前端在频谱图上标注激励频率 `f₀`，据此判断：主峰是否对准 `f₀`、有无谐波峰、噪声底水平。任何一项异常都提示采集或前端有问题。

## 8. 频域等效电路拟合

`app/dsp/circuit_fit.py`

跨整个扫频的所有频率点 `(f_i, Z_i)`，拟合一个等效电路模型，提取 R/L/C 等参数。这是**与 §3 不同的另一层拟合**：§3 是每个频率上的时域正弦拟合（得 Z）；本节是跨频率的电路模型拟合（得 R/L/C）。

### 8.1 模型库

| 模型 | 阻抗表达式 |
|------|------------|
| 串联 RLC | `Z = R + j·(ωL − 1/(ωC))` |
| 串联 RC  | `Z = R − j/(ωC)` |
| 串联 RL  | `Z = R + j·ωL` |
| 并联 RLC | `Z = 1 / ( 1/R + j·(ωC − 1/(ωL)) )` |
| 并联 RC  | `Z = 1 / ( 1/R + j·ωC )` |
| 并联 RL  | `Z = 1 / ( 1/R − j/(ωL) )` |

### 8.2 优化策略

- **在 log10(p) 空间优化**：R/L/C 跨越多个数量级（如 L 可能 1 mH = 1e-3、C 可能 1 µF = 1e-6），直接在原空间拟合会让大量级参数主导梯度。log 空间让各参数贡献均衡。
- **联合实部+虚部残差**，并用 `|Z|` 归一化以平衡高低频权重：

  ```
  residual = concat[ (Re(Z_model) − Re(Z_meas)) / |Z_meas|,
                     (Im(Z_model) − Im(Z_meas)) / |Z_meas| ]
  ```

- **求解器**：`scipy.optimize.least_squares`，`method='trf'`，带 box 约束（log 空间物理边界：R ∈ [1e-3, 1e9] Ω，L ∈ [1e-9, 1e3] H，C ∈ [1e-15, 1] F）。
- **初值**（数据驱动，避免陷局部极小）：
  ```
  R₀ = median(Re Z)
  C₀ 由最负电抗点估：X = −1/(ωC)  →  C₀ = −1/(ω·X_min)
  L₀ 由最正电抗点估：X =  ωL     →  L₀ =  X_max / ω
  ```

### 8.3 输出与质量评估

```
params       : {R, L, C, ...}
theory curve : 在 [f_min, f_max] 上 200 点 log 网格重算 Z_model，供 Bode/Nyquist 叠加
RMSE         = √( mean |Z_meas − Z_model|² )
accuracy     = 1 − RMSE / mean|Z_meas|        （越接近 1 越好）
```

## 9. OSL 校准（可选，随硬件启用）

`app/dsp/calibration.py`、`app/models/db.py:CalibSet`

模拟前端在 V、I 两通道上引入不同相移，线缆引入寄生参数；不校准则容性/感性相位和 D/Q 都不准。三步校正（校准数据**按频率存储**，因相移频变）：

```
1. 短路 Short : DUT 短接，测 Z_short        → 扣串联引线     Z₁ = Z_meas − Z_short
2. 开路 Open  : DUT 开路，测 Z_open         → 扣并联寄生(导纳域)  Y₂ = 1/Z₁ − 1/Z_open ;  Z₂ = 1/Y₂
3. 负载 Load  : 接已知 Z_load_true          → 校增益/相位     k = Z_load_true / Z₂(load) ;  Z_DUT = k · Z₂
```

> 精确的误差模型（误差适配器的拓扑）随 ESP32 模拟前端硬件定型后最终确定；以上是通用且可复用的序列，API 层仅在校准集被显式选择时才调用。

## 10. 数值验证

模拟器（`app/services/simulator.py`）按已知物理模型生成 `i(t)=I₀·sin(ωt)`、`v(t)=I₀·|Z|·sin(ωt+∠Z)`（可加噪声 / 直流 / 谐波），平台从波形反推，验证整条链路：

- **串联 RLC**（R = 50 Ω, L = 1 mH, C = 1 µF）扫频 100 Hz – 100 kHz，30 点，0.5% 噪声：
  - 恢复 **R = 49.99 Ω / L = 1.000 mH / C = 1.000 µF**，`accuracy = 99.93%`。
  - 逐频吻合，例如 100 Hz：`|Z|` 测量 1590.8 / 理论 1591.7，相位 −88.21° / −88.20°；谐振点（约 6.3 kHz）`|Z|` 触底 ≈ R。
- **pytest**：`tests/test_sine_fit.py`（已知正弦恢复幅值/相位）、`tests/test_impedance.py`（R/C/L 三种元件）、`tests/test_circuit_fit.py`（串联 RLC/RC、并联 RC 模型参数恢复）全绿。
