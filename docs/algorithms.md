## 1. 测量不确定度传播（`sine_fit.py` / `impedance.py`）

三参数正弦拟合 `x[k] ≈ a·sin(ωt) + b·cos(ωt) + c` 之后的残差 RMS
`σ_x = rms(x − x̂)` 是该通道噪声（含谐波失真）的无偏估计（自由度修正可忽略）。

阻抗由双通道幅相得到：

```
|Z| = A_v / A_i        ∠Z = φ_v − φ_i
```

对数域一阶误差传播：

```
σ_{ln|Z|} = sqrt( (σ_v/A_v)² + (σ_i/A_i)² )        →  σ_{|Z|} = |Z|·σ_{ln|Z|}
σ_{∠Z}    = sqrt( φ_v²_err + φ_i²_err ),  φ_err ≈ σ_x / (A·√(N/2))
```

复数 Z 的每点 1σ 噪声（供后续加权拟合使用）：

```
σ_Z = sqrt( (σ_{|Z|}·cos∠Z)² + (|Z|·σ_{∠Z}·sin∠Z)² , 同理取虚部 )   简化为
σ_Z ≈ |Z| · sqrt( (σ_v/A_v)² + (σ_i/A_i)² )          （工程近似，量级正确）
```

实现：`impedance.measure_impedance` 返回 `z_sigma`，随 Measurement 入库，
是所有「误差棒 / 置信带 / 加权拟合」的数据来源。

## 2. 矢量拟合 Vector Fitting（`rational_fit.py`）

### 2.1 模型

对整个扫频的离散 Z(f) 拟合有理函数（s 域极点-留数形式）：

$$
Z(s) \;\approx\; \sum_{k=1}^{N} \frac{c_k}{s - a_k} \;+\; d \;+\; s\,e,
\qquad s = \mathrm{j}2\pi f
$$

- 复极点成共轭对出现（实网络的 Z(conj s) = conj Z(s)）；
- `d`：高频串联电阻；`e`：串联电感（s→∞ 主导项）；
- **电路结构（极点个数/分布）由数据决定**，不预设任何 RLC/RC 拓扑公式。

### 2.2 极点重定位迭代（Sanathanan–Koerner / Gustavsen–Semlyen）

引入与当前极点同基的"权函数" σ(s)，解增广线性最小二乘：

$$
\sum_k \frac{c_k}{s-\tilde a_k} + d + s e
\;=\;
\Bigl(1 + \sum_k \frac{\tilde c_k}{s-\tilde a_k}\Bigr) Z(s)
$$

未知量 `(c, c̃, d, e)` 全部线性。σ(s) 的零点即新极点 —— 由伙伴矩阵特征值给出：

$$
\tilde A = \mathrm{diag}(\tilde a) - \mathbf{1}\,\tilde c^{\mathsf T},
\qquad a_k^{(\text{new})} = \lambda_k(\tilde A)
$$

每次迭代后**稳定化**：右半平面极点翻入左半平面（`Re>0 → −Re`）。
迭代 5 次后极点冻结。

注意重定位阶段**不做**共轭平均：VF 常把共轭对迁移成两个不同的实极点
（RC 型行为），平均会坍缩它们、破坏迭代。严格共轭对称化只发生在
最终分类阶段。

初始极点：在测量频带内对数均匀分布的弱阻尼共轭对 `a = −ω/100 + jω`；
每阶跑两组起点（阻尼 100 与 10），取加权 RSS 最优 —— 重定位是定点迭代，
对起点轻度敏感。

### 2.3 极点分类与原点极点

重定位结束后对极点做分类：

- **实极点**：`|Im a| ≤ max(1e-9·scale, 1e-3·|a|)`（近实数的共轭对 =
  两个实极点，各自综合成并联 RC，而不是 β→0 的谐振对——那会得出
  GH 量级的元件）；重合实极点合并（留数相加）；
- **共轭对**：取 Im>0 成员，与共轭伙伴平均；
- **原点极点**（结构性，始终加入）：项 `c₀/s` = **串联电容**。
  带外谐振节（谐振频率高于扫描带宽）在带内表现为纯电容，没有原点
  极点时 VF 会用带外非无源极点对来伪造它。

### 2.4 实参数化终解 + 非线性抛光

**终解**：固定极点位置，用全实未知量的 LS 解留数 —— 每对共轭极点
2 个实未知量 (Re c, Im c)、每个实极点 1 个、d 与 e 强制实数。设计矩阵
按 `col = φ + φ̄`（∂/∂Re c）与 `col = j(φ − φ̄)`（∂/∂Im c）构造，行按
σ 加权、列按范数缩放。这保证模型是严格的实系数有理函数——复数 d/e
与近实数偶极子之间的数值抵消不再被破坏。

**抛光**（`_polish`）：VF 收敛的极点仍可能差 ~1%，固定极点的留数解
无法弥补。用 `scipy.optimize.least_squares` 联合微调极点位置+留数
（每对 4 个实参数，原点极点钉死在 0，实部限制在开左半平面），
σ 加权残差，`x_scale='jac'`。若固定极点解已达到噪声水平且可无源
实现则跳过（快路径）。

### 2.5 无源性剪枝

抛光后逐极点检查可实现性，不可实现的**剪掉后重抛光**，循环：

- 实极点：留数 ≤ 0 → 剪（负留数 = 有源）；
- 共轭对：`u = Re c ≤ 0` → 剪；γ 越界 → 剪。**容差是元件级的**：
  无损耗节（真实 γ=0，如纯并联 RLC）的 γ 会被噪声扰成正或负，
  因此判据不是 γ 的符号，而是综合出的元件
  `−R_s ≤ 5%·R_p`（代数上 A 相消：`−γ(2α−γ) ≤ 0.05·[(α−γ)²+β²]`）。

### 2.6 阶数选择

阶数从 1 逐级升到 N_max：某阶 χ²_red ≤ 4（残差已到噪声水平）即**立即
返回该阶**——更高阶只会过拟合并浪费抛光时间。全部不可接受时回退到
最优 AICc：

$$
\mathrm{AICc} = n\ln\frac{\mathrm{RSS}}{n} + 2k + \frac{2k(k+1)}{n-k-1},
\qquad n = 2M,\quad k = 4N + 3
$$

RSS 为 σ 加权残差平方和（无 σ 时用相对权 `|Z|·1e-3`）。

### 2.7 零点

分子多项式 `N(s) = (e·s + d)·∏(s−a_j) + Σ_k c_k ∏_{j≠k}(s−a_j)`
由卷积构造后 `np.roots` 求根。极零图用于前端 s 平面可视化。

## 3. Foster 网络综合（`synthesis.py`）

把拟合出的极点-留数模型**综合成具体的 RLC 电路**（Foster 1st form，阻抗串联链）。
每个部分分式项对应一个物理支路：

| 模型项 | 电路支路 | 元件公式 |
|---|---|---|
| 常数 `d` | 串联电阻 | R = d |
| `s·e` | 串联电感 | L = e |
| 原点极点，留数 `c₀>0` | 串联电容 | C = 1/c₀ |
| 实极点 `a=−p`, 留数 `c>0` | 并联 RC | C = 1/c, R = c/p |
| 共轭对 `a=−α±jβ`, 留数 `c=u±jv` | ∥{C, R, 串RL}（见下） | — |

微小负值 `d`/`e`（|值| ≤ 0.1%·median\|Z\|，拟合噪声）直接省略，
不做负电阻/负电感。

### 3.1 共轭对支路推导

共轭对合并：

$$
\frac{c}{s-a} + \frac{\bar c}{s-\bar a}
= \frac{A s + B}{s^2 + 2\alpha s + \Omega^2},
\quad
A = 2u,\quad B = 2(u\alpha - v\beta),\quad \Omega^2 = \alpha^2+\beta^2
$$

对该支路取**导纳**做多项式除法（γ = B/A）：

$$
Y(s) = \frac{s^2+2\alpha s+\Omega^2}{A s + B}
= \frac{1}{A}\Bigl[\,s + (2\alpha-\gamma) + \frac{(\alpha-\gamma)^2+\beta^2}{s+\gamma}\,\Bigr]
$$

三项分别是电容、电阻、串联 RL 的导纳：

$$
C_p = \frac{1}{A},\qquad
R_p = \frac{A}{2\alpha-\gamma},\qquad
L_s = \frac{A}{(\alpha-\gamma)^2+\beta^2},\quad
R_s = \frac{\gamma A}{(\alpha-\gamma)^2+\beta^2}
$$

**可实现性（无源正实）条件**：`A > 0`（u>0）、`0 < γ < 2α`。
γ 在噪声级小负值（|R_s| ≤ 5%·R_p，见 §2.5）时按 γ=0 处理——串 RL 退化为
纯 L，这只发生在真实无损耗节（纯并联 RLC 的 B 恰为 0）。

### 3.2 输出

结构化网表树（前端直接渲染原理图）：

```json
{"type": "series", "children": [
  {"type": "L", "L": 1.2e-6},
  {"type": "parallel", "children": [
    {"type": "C", "C": 1e-9},
    {"type": "R", "R": 330.0},
    {"type": "series", "children": [{"type":"R","R":2.1}, {"type":"L","L":3e-6}]}
  ]},
  {"type": "R", "R": 12.3}
]}
```

另提供 `spice()` 导出（`.subckt`，串联链自动编号中间节点）与无源性检查
（密集网格上 min Re Z(jω) ≥ 0，违反则置 `passive=False` 并告警）。

## 4. 固定拓扑精修拟合（`topology_fit.py`）

作为 VF 的可解释对照组：扩展拓扑库（series/parallel RLC/RC/RL、
R+L∥C、Rs+Rp∥C），改进点：

1. **log10 参数空间** + Latin 超立方多起点（每拓扑 ~24 个起点，取代价最小者），
   消除单点初值落入错误局部极小；
2. **σ 加权残差**（同 VF）：`r = [(ReΔ/σ), (ImΔ/σ)]`，用入库的每点测量噪声；
3. **鲁棒损失** `soft_l1`（f_scale = 中位 σ）抑制坏频点；
4. **参数置信区间**：`cov = (JᵀJ)⁻¹·s²`（log 空间），95% CI =
   `10^{x* ± 1.96·σ_x}`；
5. 报告收敛状态（`sol.success`），不收敛标记而非静默。

## 5. 自动模式与模型选择（`fit_auto.py`）

`model="auto"` 时的候选集 = {VF 的每个阶数} ∪ {全部固定拓扑}，
统一用同一测量 σ 加权的 RSS 计算 AICc 排名：

- VF 阶数 N：k = 4N + 2；
- 固定拓扑：k = 参数个数。

返回最优 + 完整排名表（前端展示）。若 VF 最优不可无源综合，
综合结果仍给出但带告警，排名中 χ²_red/AICc 不变（拟合优度与可实现性是两件事）。
