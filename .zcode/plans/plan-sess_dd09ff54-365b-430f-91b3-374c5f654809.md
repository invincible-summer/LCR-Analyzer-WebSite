# LCR Analyzer 重构计划

核心路线（已确认）：**矢量拟合（Vector Fitting）+ 网络综合** 作为自动拟合引擎，固定拓扑库作为可解释精修选项，两者统一在一个「模型比较」框架下；前端重做为**浅色科学期刊图表风**（Origin/Keysight IA/matplotlib 质感）；上传 API 契约保持兼容。

---

## 一、后端 DSP 重构（`backend/app/dsp/`）

### 1. 保留并强化时域部分
- `sine_fit.py`（IEEE-1057 三参数正弦拟合）算法本身正确，保留；补充输出每通道噪声估计 σ（残差 RMS），用于后续加权与不确定度传播。
- `impedance.py`：增加 |Z| 与 ∠Z 的误差传播（由 V/I 两通道 σ 推出），随 Measurement 一起入库——这是后面所有「误差棒/置信带」的数据来源。

### 2. 新增 `rational_fit.py`（核心，矢量拟合）
- 用 pole-residue 模型拟合 Z(f)：`Z(s) ≈ Σ c_k/(s−a_k) + d + s·e`，Sanathanan-Koerner 迭代做极点重定位，共轭复极点对成组处理。
- 极点稳定化（翻入左半平面）、阶数自动选择（从低阶逐级升，AICc + 残差白噪检验选阶，防止过拟合）。
- 输出：极点/零点、留数、d、e、每点拟合残差、χ²_red、AICc。
- 可选鲁棒化：留数迭代用 IRLS/soft_l1 抑制坏点。

### 3. 新增 `synthesis.py`（Foster 网络综合）
- 对每个共轭极点对 → 串联支路里的并联 RLC 节；实数极点 → RL 节；d → 串联电阻；e → 串联电感（Foster 1st form）。
- 校验可实现性（留数实部 ≥ 0，即无源正实），不可实现时给 warning 并降阶重试。
- 输出**结构化网表树**：`{type:"series", children:[{type:"R", R:...}, {type:"RL", R,L}, {type:"RLC_p", R,L,C}, ...]}`，前端直接据此画原理图；同时可导出 SPICE 子电路文本。

### 4. 重写 `circuit_fit.py` → `topology_fit.py`
- 拓扑库扩展：原 6 种 + `R+L∥C`、`Rs+Rp∥C`（电解电容/电化学典型模型）等。
- 拟合质量修复：**Latin hypercube 多起点**（log 空间采样）替代单一启发式初值；残差按每点测量 σ 加权；`loss='soft_l1'`；从 `sol.jac` 计算协方差 → 参数 95% 置信区间；记录收敛状态。

### 5. 新增 `fit_auto.py` 调度层
- 自动模式：VF + 综合给出结构与初值 → 固定拓扑库全部拟合 → 所有候选（VF 阶数 + 各拓扑）按 AICc 排序 → 返回最优 + 完整排名表。
- 校准 `calibration.py`：改为**逐频点复数** load 校正（load_true 改复数），不再是全局中值。

## 二、后端 API / 数据库

- 上传契约（`/scan/start`、`/point`、`/batch`、`/ws/live`）不动。
- `POST /fit` 支持 `model="auto"`（VF）或具名拓扑；返回体扩展为：网表树、极零点列表、参数+置信区间、指标（χ²_red、AICc、rmse）、密集理论曲线。`FitResult` 表加 `kind`（vf/topology）、`netlist`、`ranking` 字段。
- 导出增加 SPICE `.subckt` 格式。

## 三、前端重构（`frontend/`）

### 设计系统（重写 `style.css` + `palette.ts`）
- 浅色为主：白/极浅灰底、细发丝网格、无渐变无辉光无 emoji 图标（引入 `lucide-vue-next`）。
- 自托管字体（IBM Plex Sans + IBM Plex Mono，数字 tabular-nums）；调色板单一来源：CSS 变量为真源，图表 palette 从同一组 token 派生，消除双套色板不一致。
- 图表带**编号与图注**（Fig. 1 — Bode magnitude…），报告式排版；教程性大段文字移入 tooltip/折叠的「说明」区。

### 图表升级（`charts.ts`）
- Bode/Nyquist 加 dataZoom（缩放平移）、光标交叉读数、log/lin 切换；拟合曲线支持由 VF 极点扰动生成的**置信带**；V/I 仍分图（保持现有约定）。

### 视图重点重做：FitView（拟合可视化，本次核心）
- 默认「自动模式」：结果区展示 **SVG 交互原理图**（由网表树渲染，元素上标注数值与置信区间）、极零点图（s 平面）、模型排名表（各候选 AICc/χ²）、残差 vs 频率图。
- Bode/Nyquist 叠加理论曲线；参数表含 CI；可切换查看排名第 2/3 的候选模型。

### 其余视图
- AnalysisView / SweepView 沿用流程但换新皮肤与图表；LiveView、HistoryView 精修；CalibrateView 保持极简占位。

## 四、测试（`backend/tests/`）

- 新增 `test_rational_fit.py`：由已知 Foster 网络（2–3 节 RLC）生成 Z(f)，验证极点/留数恢复；加噪声、窄频带、错误阶数场景。
- 新增 `test_synthesis.py`：极零点 → 网表元素值正确、无源性校验。
- 重写 `test_circuit_fit.py`：多起点收敛、CI 合理性、模型排名选中真实模型、含噪数据。
- 现有 sine_fit/impedance 测试保留通过。

## 五、文档

- 按仓库惯例同步 `README.md`（新增矢量拟合/网络综合/模型选择公式推导与实现细节）与 `docs/api_contract.md`（fit 响应体变更）。

## 实施顺序

1. 后端 DSP：`rational_fit` → `synthesis` → `topology_fit` → `fit_auto`（含单测，逐个可验证）
2. 后端 schema/API/导出 + 测试
3. 前端：设计系统与字体图标 → charts 升级 → FitView（原理图/极零图/排名）→ 其余视图换肤
4. 模拟器生成复杂电路数据，端到端验证（mock 拟合出的非平凡网络）
5. 文档同步

风险点：矢量拟合在窄频带/高噪声下可能选阶不稳——通过 AICc + 逐级升阶 + 残差白噪检验缓解，且固定拓扑候选兜底，排名表对用户透明。
