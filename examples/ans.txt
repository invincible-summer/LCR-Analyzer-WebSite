examples/ 数据集结构答案（ans.txt）
====================================

四份文件均来自 AUTO SWEEP RESULT（对数扫频 10 Hz – 10 kHz），已整理为
拟合页可上传的 CSV：每行三个逗号分隔数 f_Hz, Re(Z)_ohm, Im(Z)_ohm，
`#` 开头为注释行。

用法：拟合页 → 顶部数据面板 → 「上传 CSV」→ 选择 dataN.csv → 在
Try1 / Try2 / Try3 栏目中搜索拟合，与下述答案对照。

────────────────────────────────────────────────────────
data1.csv（40 点）
  结构：R ∥ C
  数值：R = 10 kΩ，C = 100 nF
  特征：低频 |Z| → 10 kΩ；转折频率 1/(2πRC) ≈ 159 Hz，之后 |Z| 以
        −20 dB/dec 下降、相位趋于 −90°。

data2.csv（20 点）
  结构：[L + DCR] ∥ C   （带直流电阻的实际电感，与 C 并联）
  数值：L = 100 mH，DCR = 345 Ω，C = 1 µF
  特征：低频 |Z| → DCR ≈ 345 Ω；约 500 Hz 处 L∥C 并联谐振，但 Q < 1
        （Q = ω0L/DCR ≈ 0.9），峰值仅数百 Ω；高频呈容性 |Z| ≈ 1/(2πfC)。
        注意 L+DCR 在本站语义中算 1 个器件（2 个参数）。

data3.csv（40 点）
  结构：([L + DCR] ∥ C1) 串联 C2
  数值：L = 100 mH（DCR ≈ 345 Ω，与 data2 同一实际电感模型），
        C1 = 100 nF，C2 = 1 µF
  特征：低频容性（C2 主导，|X| ≈ 1/(2πf·C2)）；约 500 Hz 起转感性；
        1.6 kHz 附近 L∥C1 并联谐振（|Re| 峰 ≈ 2.8 kΩ，被 DCR 限制），
        之后回容性。本组数据含明显噪声（个别点 Re 有 ±百 Ω 抖动）。

data4.csv（40 点）
  结构：R2 串联 (R1 ∥ L ∥ C)   —— 并联槽路再串 R2
  数值：R2 = 50 Ω；R1 = 200 Ω；L = 820 µH（DCR ≈ 13 Ω），C = 1 µF
  特征：低频 |Z| → R2 + R1∥DCR ≈ 50 + 12 ≈ 62 Ω（实测平线 62.1 Ω，
        这条渐近线正是 L 带 DCR 的证据）；4–5 kHz 附近槽路由感转容，
        |Z| 有宽峰 ≈ 107 Ω；高频趋向 R2。

────────────────────────────────────────────────────────
Try3 边表（可整段粘贴进图编辑器左侧文本面板，0/1 为端口节点）：

  data1:
    0 1 R
    0 1 C

  data2:
    0 1 L
    0 1 C

  data3:
    0 2 L
    0 2 C
    2 1 C

  data4:
    0 2 R
    0 2 L
    0 2 C
    2 1 R

边表只声明类型（R/L/C），元件数值由 Try3 拟合求出；上行类型即答案
拓扑。data2/data3/data4 中的 L 均带 DCR（拟合应给出 L 与 DCR 两个值）。

────────────────────────────────────────────────────────
数值核对（按上述结构对四份数据做最小二乘复核；数据含噪声与元件
容差，回收值与标称略有出入，拟合引擎得到接近下列值即为正确）：

  data1  R∥C          R = 9.93 kΩ     C = 102.8 nF        wRMSE ≈ 0.9 %
  data2  (r+L)∥C      r = 335 Ω       L = 100.9 mH        C = 0.95 µF    wRMSE ≈ 1.9 %
  data3  ((r+L)∥C1)+C2 r = 355 Ω      L = 105.6 mH  C1 = 102 nF  C2 = 0.98 µF  wRMSE ≈ 2.1 %
  data4  R2+(R1∥L∥C)  R2 = 52.4 Ω     L = 802 µH    C = 0.9 µF     wRMSE ≈ 0.5 %
                       （R1 与 r、C 强相关，R1 回收值 138 Ω 偏离标称 200 Ω，
                         但结构唯一：串联/无损 L 等替代结构的误差大 8 倍以上）

结论要点：
  * 四组数据均为 SP（串并联）网络，SP 电路图可直接渲染。
  * data2/3/4 的电感必须按「L + DCR」建模才能拟合好（无损 L 结构
    wRMSE 差一个数量级）。
  * 元件实际值与标称值存在 ±5% 左右容差（如 data2 的 C 回收 0.95 µF），
    评价拟合结果时应与「回收值」而非标称值比较。
